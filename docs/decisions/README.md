# Architecture decisions

Record decisions that constrain future implementation or are expensive to reverse. Do not create an ADR for routine code choices.

Use sequential files such as `0001-text-first-vertical-slice.md`:

```markdown
# Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context
Facts, constraints, and forces that make a decision necessary.

## Decision
The chosen direction.

## Consequences
Benefits, costs, risks, and follow-up work.

## Alternatives considered
Credible alternatives and why they were not selected.
```
